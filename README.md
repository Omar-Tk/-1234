مشروع الحاسبة - Flutter
======================

الملف الرئيسي: main.dart

طريقة التركيب داخل مشروع Flutter:
1) أنشئ مشروعاً جديداً:
   flutter create my_calculator

2) افتح مجلد المشروع، ثم استبدل الملف:
   lib/main.dart
   بالملف main.dart المرفق.

3) شغّل التطبيق للتجربة:
   flutter run

4) لإنشاء ملف APK للأندرويد:
   flutter build apk --release

ستجد ملف APK الناتج عادةً هنا:
   build/app/outputs/flutter-apk/app-release.apk

المميزات:
- جمع وطرح وضرب وقسمة.
- النسب المئوية والإشارات والأعداد العشرية.
- مراعاة أولوية العمليات الحسابية.
- عرض النتيجة أثناء الكتابة.
- سجل آخر 30 عملية.
- الوضع الليلي والنهاري.
- لا يحتاج إلى أي مكتبات خارجية إضافية.

ملاحظة: هذا ملف مصدر Flutter (Dart)، وليس APK جاهزاً. يجب وضعه داخل مشروع Flutter ثم بناء التطبيق.
